Fabtech FTL5607 1.5" Leveling Kit for 2024–2026 Toyota Tacoma & 2025–2026 4Runner

The Fabtech FTL5607 Toyota Tacoma leveling kit adds approximately 1.5 inches of front ride height using CNC-machined billet aluminum spacers above the factory coilover assemblies. It is designed for 2024–2026 Toyota Tacoma 2WD/4WD and 2025–2026 Toyota 4Runner 4WD applications, helping reduce the factory nose-down stance while creating additional tire clearance.

Fabtech FTL5607 product details

FTL5607 is a front leveling system that works with the factory coilover shock assemblies. The billet spacers install above the coilover, so the factory coilover does not need to be disassembled for the spacer installation. The system is engineered to add front height while maintaining suspension travel and steering geometry within Fabtech's intended operating range.

Key features

  • 1.5-inch front leveling system for late-model Toyota Tacoma and 4Runner applications.
  • CNC-machined billet aluminum front spacers with high-grade installation hardware.
  • Designed to work with the factory coilover assemblies without coilover disassembly for the spacer install.
  • Additional front ride height can help level the vehicle stance and create clearance for larger tire-and-wheel combinations.
  • Fabtech lists a 5-year / 60,000-mile powertrain warranty for this leveling system.

Some vehicles may not sit perfectly level after installation. Confirm your exact trim and suspension configuration before ordering.

Tire & wheel guidance
